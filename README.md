# Carr+
A system of functions used to generate and edit audio to use in parallel or instead of a DAW.
So far it is the only version that exists. It can provide tools a DAW doesn't have like a varispeed where you can control the speed, a good amount of high quality effects and a synth engine. A few warnings: it does not have comments. I will add comments one day. The system is NOT a VST and NOT suitable for real time use. It is extremely slow compared to modern VSTS which run in C++ while this is python. On the other hand, it can be edited easily by anyone with knowledge of python, includes functions that break the DAW grid.
It is simultaneously a complement to a DAW, providing easy wavefolding, varispeed with speed automation and glich, also letting you synthesize and vocode audio, filling gaps in features, but it is also a good tool for learning DSP basics and making your own effects or editing premade ones. For fans of Aphex Twin style text based music making, Carr+ has got you covered.
Its a sort of hackable music engine. Anyone can try it out, a person who wants to learn DSP, a musician looking for quick ways to get access to some features or even a programmer looking to have fun.
